# 🚀 PitchPilot AI Startup Coach

PitchPilot is an AI-powered startup validation platform that helps entrepreneurs analyze and improve their business ideas before building them.

Users enter a startup idea, and PitchPilot AI generates structured insights including SWOT analysis, market opportunity analysis, business strategies, risk evaluation, and investor-ready pitches.

---

## ✨ Features

- 🤖 AI Startup Idea Analysis
- 📊 Startup Potential Score
- SWOT Analysis Generator
- 📈 Market Opportunity Analysis
- 💼 Business Strategy Generator
- ⚠️ Risk Evaluation
- 💡 AI Recommendations
- 📝 Investor Pitch Generator
- 💾 Save and view previous analyses
- 📄 Download AI Report PDF

## ⚙️ Installation

Clone the repository:

```bash
git clone your-repository-link
```

Install dependencies:

```bash
npm install
```

Create a `.env` file:

```env
VITE_SUPABASE_URL=your_supabase_url
VITE_SUPABASE_KEY=your_supabase_key
VITE_OPENAI_API_KEY=your_api_key
```

Run the project:

```bash
npm run dev
```

---

## 📌 How It Works

1. User enters a startup idea.
2. PitchPilot AI analyzes the idea.
3. AI generates:
   - SWOT Analysis
   - Market Opportunity Analysis
   - Business Strategy
   - Risk Evaluation
   - Investor Pitch
4. Users can save and review previous startup analyses.
